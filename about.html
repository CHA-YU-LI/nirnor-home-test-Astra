02 / 第一次使用

從好奇，到親手試試。

  1. 先體驗畫面

    到首頁試著移動、點擊與切換材質。手機可以依提示使用觸控和按鈕操作。

  2. 挑一個感興趣的效果

    進入特效庫搜尋或篩選，再點選卡片開啟獨立 demo。組合展示則讓你觀察多個效果如何一起運作。

  3. 調整參數，觀察差別

    依效果調整速度、時間或強度。「重播」重新播放效果，「重設」恢復預設參數；捲動型效果請在展示區內往下捲，再反向試試。

  4. 看懂原理，帶進自己的專案

    往下閱讀實際使用的套件、版本與 API，再複製使用範例。依照依賴清單準備必要檔案，透過本機 HTTP 伺服器預覽。

上方導覽會固定在畫面頂端，隨時都能切換頁面。手機請點選右上角選單；網站也提供減少動態的對應行為，細節可在各 demo 的技術說明中查看。

03 / 創作理念與來源

讓細微的動作，
成為可以理解的設計。

動態實驗室從形體、光影、文字與留白出發，觀察一個小小的動作如何改變畫面的感受，再將它整理成可以操作與調整的實驗。

特效研究以 NIRNOR（在新分頁開啟） 的公開網站為靈感來源，採用自製文字、幾何圖形與替代素材。本站是獨立研究，並非 NIRNOR 官方網站。

重現效果與原站之間仍有差異；目前各效果的完整瀏覽器互動驗證仍待完成。「已實作」不代表「已通過全部驗證」，請以各 demo 與觀察紀錄的狀態為準。
